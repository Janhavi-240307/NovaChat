# NovaChat
NovaChat is a full-stack AI chat application inspired by modern conversational AI platforms. It allows users to create and manage conversations while interacting with an AI assistant through the OpenAI API.

## Features
- User registration and login
- Secure password hashing using bcrypt
- AI-powered conversations using OpenAI API
- Create new chats
- Persistent chat history
- Conversation/thread management
- Rename & export conversations(still working on it)
- Delete conversations
- MongoDB-based message and thread storage
- Markdown rendering for AI responses
- Syntax highlighting for code responses
- Responsive chat interface
- Separate Chat Mode and Interview Mode structure

**Note:** Chat Mode is currently functional, while Interview Mode is under development.
